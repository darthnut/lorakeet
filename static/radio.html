3 Channels

A radio reads the channels it has the key for. A private channel of your own (for your radios, or friends and family) keeps your messages and test traffic off the public channel.

Key: Public default key = the well-known key every Meshtastic radio has, so anyone can read it (that's the point of the main public channel). Private key = only radios given this channel's key can read it. Primary's key = it borrows the primary channel's key. Positions: how precisely this radio shares its own position on that channel: exact, rounded (13 bits is a box about 5 km across; more bits = more precise), or not shared. Lorakeet logs every channel the radio can read, whichever one you send on.

Make a private channel

A new channel with a random 256-bit key, added to this radio. Then share it: scan its QR code in the Meshtastic app on your phone (for a radio paired with it), or copy it to another radio plugged into this computer.

Add a channel from a link

Someone shared a channel with you? Paste its Meshtastic link (https://meshtastic.org/e/#…). Channels already on the radio are never replaced.

4 Logging

A live check since you opened this page. Packets are the messages, positions and telemetry the radio decoded. Per-reception detail is each copy of a packet as it arrived over the air, relayed or repeated: it's what the replay, relays and airtime are built from. All three ticked means everything the radio hears is being kept.

Backups

Taken before every change, in (readable only by your user account). They hold the radio's private key and channel keys: keep them private. To restore one: meshtastic --port <port> --configure <file>, with logging paused (tray icon → Pause logging) or Lorakeet stopped, since only one program can use the radio's port.
